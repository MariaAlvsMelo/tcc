Bem-vindo ao Entre Notas!

Este site é um portal interativo dedicado aos amantes da música, criado com o objetivo de conectar pessoas através de suas opiniões, notas e resenhas sobre álbuns, faixas e artistas favoritos. Aqui, cada nota conta e cada ritmo ganha voz.

Esta plataforma nasceu como um Projeto de Conclusão de Curso (TCC) para o Ensino Médio Técnico em Análise e Desenvolvimento de Sistemas na instituição Tenista Maria Esther Andion Bueno.

O projeto unifica o aprendizado prático de desenvolvimento web front-end e back-end, banco de dados e design de interface, transformando linhas de código em uma experiência social e musical.

Tecnologias Utilizadas

Para construir um ambiente seguro, rápido e responsivo, utilizamos as seguintes tecnologias: HTML, CSS, JavaScript e MySQL.
