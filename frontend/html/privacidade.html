Política de Privacidade & LGPD

Conheça como as informações são utilizadas na plataforma Entre Notas.

Como Tratamos Seus Dados

1. Coleta de Informações

O Entre Notas solicita informações como nome, e-mail e senha durante o cadastro para identificação do usuário e acesso à plataforma.

2. Foto de Perfil

O usuário pode selecionar uma imagem de seu dispositivo para personalizar seu perfil. A seleção acontece quando o próprio usuário utiliza essa funcionalidade.

3. Avaliações e Interações

O sistema registra avaliações musicais, notas por estrelas, comentários e curtidas associados aos usuários. Essas interações podem ser exibidas publicamente no Feed da plataforma.

4. Preferências de Navegação

Preferências como modo noturno e configuração de métricas são armazenadas localmente no navegador para preservar as escolhas realizadas.

5. Direitos dos Usuários

A Lei Geral de Proteção de Dados Pessoais (LGPD) estabelece direitos relacionados ao acesso, correção e exclusão de dados pessoais, conforme as condições previstas na legislação.

6. Segurança das Informações

O armazenamento e o acesso aos dados devem utilizar medidas adequadas de segurança para proteger as informações pessoais.

Este é um texto inicial para o projeto escolar Entre Notas. Antes de disponibilizar a plataforma publicamente, é necessário revisar esta política de acordo com as práticas reais de armazenamento, segurança, compartilhamento e exclusão de dados, além de indicar um canal de contato.
